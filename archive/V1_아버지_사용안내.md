# 아버지를 위한 미용실 예약앱 사용안내

## 처음 한 번만

1. 앱 시작 화면에서 **내 코드로 확인 · 관리자 접속**을 누릅니다.
2. 첫 칸에 **1111**을 입력합니다. 아래 고객 PIN 칸은 비워 둡니다.
3. **접속하기 → 첫 비밀번호 설정**을 누릅니다.
4. 현재 비밀번호 `1111`과 새 비밀번호를 입력합니다. 새 비밀번호는 8자 이상입니다.
5. 새 비밀번호를 다른 사람에게 알려주지 않습니다. 초기 비밀번호를 변경하기 전에는 QR을 손님에게 공개하지 않습니다.

매장 이름·주소·전화번호와 실제 가격은 앱을 설치한 가족이 먼저 설정해 주세요.

## 색과 글자의 의미

- **예약 가능**: 손님이 바로 예약할 수 있습니다.
- **확인 필요**: 손님이 신청할 수 있지만, 아버지가 승인해야 확정됩니다.
- **예약 불가**: 손님이 예약할 수 없습니다.
- **예약 확정 / 예약됨**: 이미 예약이 잡힌 시간입니다.
- **승인 대기**: 아직 승인하지 않은 신청입니다. 다른 손님은 그 시간을 예약할 수 없습니다.

아무 설정이 없는 시간은 **매일 10:00~20:00에 예약 가능**으로 시작합니다. 예약은 한 분씩 **30분 단위**이며, 마지막 시작 시간은 19:30입니다. 펌·염색처럼 오래 걸리는 시술에는 그대로 사용하지 마세요.

## 쉬는 시간 표시하기

1. 위의 날짜 버튼에서 날짜를 고릅니다.
2. 아래에서 시작 시간을 누릅니다.
3. **예약 불가**를 누릅니다.
4. 설정 길이를 입력합니다. 30분, 60분, 90분처럼 입력합니다.
5. 한 번만 쉬면 **이 날짜만**을 선택하고 저장합니다.
6. 매주 쉬면 **매주 반복**을 선택하고 해당 요일을 켭니다.
7. 계속 적용하려면 **종료 없이 계속 반복**을 켜 둔 채 저장합니다.

예: 매주 월요일 휴무 → 앞으로 올 월요일 선택 → 10:00 선택 → 예약 불가 → **600분** → 매주 반복 → 월요일만 켜기 → 저장.

예: 매일 점심 12:00~13:00 → 시작 날짜 선택 → 12:00 → 예약 불가 → **60분** → 매일 반복 → 저장.

시간 설정을 변경해도 이미 받은 예약은 자동 취소되지 않습니다. 꼭 아래 예약 내역도 확인하세요.

## 일주일 보기와 수정

- **주간 보기**: 일주일 전체 시간을 확인합니다. 휴대전화에서는 표를 좌우로 밀 수 있습니다.
- 실제 시간 수정: 위의 요일·날짜 버튼을 고르고, 아래 큰 시간 버튼을 누릅니다.
- **오늘**을 누르면 오늘로 돌아옵니다.
- 일정은 손님이 앱을 열어 둔 동안 보통 약 10초마다 갱신됩니다. 즉시 전송 알림은 아닙니다.
- 바꿀 구간에 새 설정을 저장하면 같은 종류에서는 나중에 저장한 설정이 우선합니다.
- **이 날짜만** 설정은 반복 설정보다 우선합니다. 반복 영업을 바꿨는데 특정 날짜가 그대로라면 그 날짜의 예외 설정을 확인해 주세요.
- 아래 **시간 설정 삭제**는 해당 설정 전체를 지웁니다. 반복 설정이면 반복 전체가 삭제됩니다. 예약은 삭제되지 않습니다.

## 손님 예약 확인하기

1. 해당 주를 엽니다.
2. 아래 **이번 주 예약 고객**을 확인합니다.
3. 이름, 시술, 시간, 가격, 요청사항이 나옵니다. 다른 손님에게는 이 정보가 보이지 않습니다.
4. **승인 대기**는 **예약 승인** 또는 **요청 반려**로 처리합니다.
5. 취소할 때는 **예약 취소 → 예약 취소 확정**을 누릅니다.
6. 신청은 자동으로 만료되지 않습니다. 승인 대기 예약을 제때 처리해 주세요.

전화나 방문으로 받은 예약을 이름과 함께 직접 등록하는 기능은 아직 없습니다. 당분간 그 시간을 **예약 불가**로 표시해서 중복 예약을 막아 주세요.

## 가격 바꾸기

1. **가격 수정**을 누릅니다.
2. 날짜를 고르라는 안내가 나오면 위에서 날짜를 누릅니다.
3. 시술 이름과 원화 가격을 입력합니다. **₩** 표시가 나옵니다.
4. 더 넣으려면 **＋ 시술 추가**를 누릅니다.
5. **가격 저장**을 누릅니다.
6. 그 날짜만 바꾸지 않고 기본 가격도 바꾸려면 **다른 날짜에도 적용되는 기본 가격표로 설정**을 체크하고 저장합니다.

다른 날짜에 따로 정해 둔 가격은 기본 가격을 바꿔도 유지됩니다. 이미 받은 예약에는 예약 당시 가격이 유지됩니다.

## QR 배포하기

앱을 설치한 가족이 실제 앱 주소를 등록하면 아래 **고객에게 공유하기**에 QR이 나옵니다. **매장 QR 코드 저장**으로 저장하고 출력하세요. 다른 휴대전화 카메라로 먼저 찍어 보고 배포하세요.

QR에는 공개 앱 주소만 들어갑니다. 관리자 비밀번호를 QR이나 안내문에 적지 마세요.

## 손님에게 알려 줄 내용

- 처음 시작하면 **두 자리 코드와 여섯 자리 복구 PIN**이 나옵니다. 둘 다 안전하게 보관해야 합니다.
- **24시간 안**에는 코드와 PIN으로 다시 들어와 본인 예약을 확인할 수 있습니다.
- 새 기기에서 들어오면 이전 기기는 로그아웃됩니다.
- **코드가 만료되어도 예약은 취소되지 않습니다.** 그 이후 확인·변경은 매장으로 전화하도록 안내해 주세요.
- **승인 대기**는 아직 확정이 아닙니다. 앱에서 승인 결과를 확인하거나 매장으로 문의하도록 안내해 주세요.
- 문자·카카오톡 알림 기능은 아직 없습니다.

## 매일 확인할 것

- 오전에 오늘 예약과 승인 대기를 확인합니다.
- 점심·휴무·외출·전화예약 시간을 막았는지 확인합니다.
- 예약 취소·반려는 손님과 통화 등으로 함께 확인하는 것이 좋습니다. 자동 메시지는 발송되지 않습니다.
- 관리자 이용이 끝나면 **로그아웃 · 시작 화면**을 누릅니다.
- 비밀번호 변경은 **관리자 비밀번호 변경**에서 합니다.
- 개인정보는 설치 시 설정한 자동 삭제 작업으로 예약일 약 30일 뒤 삭제됩니다. 실제 삭제 작업이 정상 작동하는지는 설치한 가족이 관리해 주세요.
